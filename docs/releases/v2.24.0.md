# QuantaPDF 2.24.0

## SVG V2B2

The bounded static SVG lowering path now supports exact local symbol reuse:

- root-defs `symbol` definitions with viewBox;
- fragment-local `use href="#symbol"` references;
- x/y/width/height placement;
- use transforms;
- symbol preserveAspectRatio none / meet / slice;
- nested acyclic symbol references.

## Form lowering

A symbol is parsed side-effect-free into copied element tokens and a dependency
set. Before publication, the full symbol dependency graph is validated for
unresolved, wrong-kind, external, and cyclic references.

On first referenced use, QuantaPDF serializes the already-owned root defs tokens
plus the symbol body tokens into a bounded synthetic SVG and renders that SVG
inside a temporary transparent child Composer. The completed child is stored by
the existing Composer Form XObject resource.

Repeated use instances therefore lower to `draw_form()`, not repeated PATH
expansion.

Nested symbols, gradients, clip paths, dash, opacity and arc normalization all
reuse the existing SVG/Composer lowering recursively.

## Placement

The symbol viewBox dimensions define the Form local dimensions. Use
x/y/width/height plus the symbol preserveAspectRatio setting produce the Form
affine transform.

For symbol `slice`, the use viewport is enforced with the existing Composer
clip/graphics-state primitive.

## V1 boundary

- only symbol targets are valid use targets;
- href must be a fragment-local `#id`;
- xlink:href and external URLs are rejected;
- presentation-style overrides on use are rejected;
- symbol requires a positive viewBox;
- unsupported symbol children fail closed;
- cyclic and unresolved dependencies fail before Composer publication.

## Transactional behavior

SVG publication snapshots operations, paints, clips, graphics states, Forms,
and resource bytes. Failure during Form materialization or placement frees new
owned resources and restores the original Composer state.

## Compatibility

No new public ABI symbols are added. ABI v2 is unchanged.

## Qualification

Focused tests cover forward references, repeated Form reuse, meet/none/slice
placement, nested symbols with gradient/clip resources, direct Form XObject
inspection, cycle/wrong-kind/external/style-override rejection, transaction
rollback, deterministic finish, PDFium rendering, and installed-package
execution.
