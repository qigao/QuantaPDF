# QuantaPDF 2.22.0

## SVG V2A

The bounded static SVG Composer path now supports:

- numeric `stroke-dasharray` and `stroke-dashoffset`;
- inherited fill/stroke opacity plus leaf opacity;
- A/a elliptical arcs normalized to cubic Bézier segments;
- root `preserveAspectRatio` with default xMidYMid meet, none, aligned meet,
  and aligned slice.

Slice lowering uses a Composer clip resource for the destination viewport.

## Semantics

Odd dash lists are duplicated, negative offsets are normalized modulo the dash
pattern, and dash geometry scales with the same conformal factor as stroke
width.

Effective shape alpha is leaf opacity multiplied by inherited fill/stroke
opacity. Group/root opacity other than 1 remains unsupported until whole-group
compositing is introduced.

A/a arcs never reach the PDF backend as a new primitive; they are converted to
cubic segments in the SVG parser.

## Transactional behavior

SVG parsing remains side-effect free. Clip and graphics-state resources are
registered only during final publish under rollback snapshots. Any failure
before operation publication restores resource counts and bytes.

## Compatibility

No new public ABI symbols are added. ABI v2 is unchanged.

SVG documents that do not use V2A properties continue through the existing PATH
lowering. Reference-bearing gradient/clip/use features remain reserved for SVG
V2B.

## Qualification

Focused coverage includes dash/opacity inheritance, arc geometry, aspect-ratio
mapping, slice clipping, fail-closed group opacity, deterministic output,
transactional failure, and installed-package execution.
