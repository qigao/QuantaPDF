# QuantaPDF 2.29.0

## SVG V3B

SVG lowering now supports exact objectBoundingBox resource semantics and local
paint templates.

### objectBoundingBox

Supported for:

- gradients;
- clipPath;
- patternUnits;
- patternContentUnits.

Each staged PATH computes an exact local geometry bbox before PATH V4 CTM.
Cubic Bézier extrema are solved analytically. Zero-area bboxes reject
objectBoundingBox resources.

The bbox coordinate transform is composed locally; the element PATH CTM remains
applied exactly once.

### Local templates

Local same-kind gradient and pattern href/xlink:href references are normalized
before rendering.

Gradient templates inherit omitted coordinates/units/transform and inherit
stops only when the derived gradient has no local stops.

Pattern templates inherit omitted units/transform/tile geometry and inherit
child content only when the derived pattern has no local content.

Cycles, unresolved references, wrong-kind references, and external hrefs remain
fail-closed.

### Pattern coordinate systems

All exact combinations of patternUnits and patternContentUnits between
userSpaceOnUse and objectBoundingBox lower through the existing Composer tiling
paint. No additional PDF backend path is introduced.

## Compatibility

No public ABI symbols are added. ABI v2 is unchanged.

Existing userSpaceOnUse V2/V3A SVG behavior remains on the same Composer
paint/clip/PATH primitives.

## Qualification

Focused tests cover exact bbox matrices, cubic extrema, clip geometry,
mixed pattern coordinate systems, template inheritance and cycles, zero-area
bbox rollback, deterministic output, PDFium rendering, and the Windows
installed-package consumer.
