# QuantaPDF 2.17.0

## Added

- `quantapdf_composer_raster_format` with Gray8, RGB24, and RGBA32.
- `quantapdf_composer_raster` for explicit dimensions, stride, pixels, and
  source byte size.
- `quantapdf_composer_add_raster()`.

## Semantics

Raw input is copied into canonical tightly packed Composer-owned storage.
Padded source strides are supported. Gray8 maps to DeviceGray, RGB24 maps to
DeviceRGB, and RGBA32 is split into DeviceRGB plus an 8-bit soft mask.

RGBA32 input uses straight/unassociated alpha.

Only canonical visible output bytes count against the Composer resource budget;
source row padding is not retained or charged.

## Compatibility

Existing JPEG/PNG registration and image drawing APIs are unchanged. Raw raster
resources return the same image IDs and lower through the existing qpdf image
backend.

## Qualification

Focused tests cover formats, padding, overflow/undersize validation, canonical
resource accounting, ownership, alpha rendering, extraction metadata,
determinism, and the installed-package consumer.
