# QuantaPDF 2.28.0

## SVG V3A

SVG lowering now consumes the Phase 5 Composer primitives for:

- userSpaceOnUse tiling patterns;
- non-conformal/skewed PATH transforms through PATH V4;
- root/group opacity through isolated transparency Forms;
- unified DOM painting order across PATH and Form-backed SVG operations.

## PATH transforms

Drawable path geometry remains in local SVG user space. The full SVG transform
is attached through PATH V4, while stroke width, dash state, cap/join and paint
resources stay local. Native PDF CTM semantics therefore handle non-uniform
scale and skew exactly.

Clip resources remain externally transformed because they are established
outside the PATH q/cm scope.

## Pattern paint

V3A pattern definitions require explicit patternUnits="userSpaceOnUse" and
user-space content units. Pattern tile content is replayed in a temporary child
Composer and registered as the existing generic tiling-pattern paint.

Pattern cycles, objectBoundingBox units, and symbol/use recursion inside tiles
remain fail-closed.

## Group opacity

Non-1 root/group opacity is materialized as an isolated transparency Form.
Child opacity is not multiplied individually. The completed group is painted
once under an outer Normal graphics-state alpha.

Nested group opacity recursively uses the same Form mechanism.

## Painting order

PATH, use/Form and opacity-group Form records share a monotonic parse order.
After transactional resource publication, the newly appended operation slice is
restored to SVG document order.

## Compatibility

No new public ABI symbol is introduced. ABI v2 remains unchanged.

SVG inputs not using V3A features continue to use the existing Composer
primitives.

objectBoundingBox units and local paint template inheritance remain SVG V3B.

## Qualification

Focused tests cover native CTM stroke/dash behavior, PatternType 1 resources,
pattern fill/stroke, repeated-cell rendering, isolated/nested/root group
opacity, DOM order, fail-closed pattern semantics, rollback, deterministic
finish and the installed-package consumer.
