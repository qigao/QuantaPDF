# QuantaPDF 2.33.0

## SVG V4B local masks

The bounded static SVG lowerer now supports local `mask` definitions and
fragment-local mask references through Composer's Form-backed soft-mask
primitive.

Supported definition controls include:

- maskUnits=userSpaceOnUse/objectBoundingBox;
- maskContentUnits=userSpaceOnUse/objectBoundingBox;
- x/y/width/height region values;
- mask-type alpha/luminance;
- local drawable/group/use content;
- nested acyclic local masks.

## Composition

Leaf masks attach through graphics-state V3 together with existing alpha,
blend and compound clip state.

Root/group masks remain outside the captured isolated transparency Form, so
group opacity and mask composition preserve SVG group semantics.

Masked `use` placements reuse the same Form/graphics-state path.

## objectBoundingBox

Leaf paths use their exact staged local geometry bbox, including cubic extrema.

For outer root/group/use staging where an exact painted bbox is not available,
V1 accepts explicit userSpaceOnUse masks. bbox/percentage semantics that would
require substituting a viewport bbox remain unsupported rather than
approximated.

## Soft-mask backend reuse

SVG V4B adds no qpdf backend path.

Mask content is rendered into an isolated reusable Form, registered through
`quantapdf_composer_add_soft_mask()`, and attached with the existing
graphics-state V3 soft_mask_id.

Alpha masks lower to /S /Alpha. Luminance masks lower to /S /Luminosity.

## Transactional/security boundary

Definition parsing is side-effect free. Mask dependency cycles, unresolved
refs, wrong-kind refs, and external URLs fail closed before publication.

SVG publication snapshots paint/clip/state/soft-mask/Form counts and owned
resource bytes. A failed mask build restores the previous Composer state.

No raster flattening, external I/O, filters or browser CSS cascade is added.

## Compatibility

No public ABI symbol changes. ABI remains v2.

## Qualification

Focused tests cover leaf Alpha/Luminosity masks, group/root mask composition,
mask content using local symbols, direct /SMask inspection, dependency errors,
zero-area bbox rejection, rollback, deterministic rendering and installed
package execution.
