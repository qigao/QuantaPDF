# QuantaPDF 2.32.0

## SVG V4A

SVG clipping now lowers through Composer's compound clip intersection primitive.

Active root/group/leaf clips, preserveAspectRatio=slice viewport clips, and
symbol/use slice clips are registered independently and combined into one
canonical clip ID per operation or Form placement.

## Exact intersection

No path boolean operation is performed. PDF clipping paths are cumulative, so
the qpdf backend emits the compound clip leaf paths sequentially with their own
W/W* operators inside the existing q/Q scope.

## Group opacity and reusable Forms

Opacity-group Forms keep ancestor/group clips on the outer Form placement while
local subtree clips remain inside the captured child SVG.

symbol/use Form placement can combine inherited/local clips with the symbol
slice viewport clip instead of rejecting multi-clip cases.

## Nested clipPath references

A clipPath may reference another local userSpaceOnUse clipPath. Acyclic chains
are recursively lowered to compound clips.

Cycles, unresolved/external references, and nested chains involving
objectBoundingBox units remain fail-closed.

## objectBoundingBox

Leaf drawable objectBoundingBox clip-path support from SVG V3B remains exact
and can participate in a compound intersection with user-space ancestor clips.

## Compatibility

No public ABI symbols or structures change. ABI remains v2.

## Qualification

Focused tests cover four-way compound clipping, opacity-group clipping,
symbol/use slice composition, nested clipPath chains/cycles, bbox mixing,
transactional rollback, deterministic output, PDFium rendering, and the
installed-package consumer.
