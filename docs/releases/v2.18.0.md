# QuantaPDF 2.18.0

## Added

- `quantapdf_composer_graphics_state_options`.
- `quantapdf_composer_add_graphics_state()`.
- Typed blend modes: Normal, Multiply, Screen, Overlay, Darken, Lighten.
- V2 graphics-state tails for text, embedded-text, glyph-run, image, and path
  option records.

## Compatibility

V1 option sizes remain at their pre-2.18 ABI boundaries. The appended graphics
state ID deliberately uses `size_t` alignment so it starts after the legacy
rounded `sizeof` boundary on both 32-bit and 64-bit ABIs rather than occupying
old tail padding.

State ID 0 is the implicit legacy state (fill/stroke alpha 1, Normal blend).
No ExtGState resource or `gs` operator is emitted for state 0.

## Backend

Referenced states lower to deduplicated PDF ExtGState resources using `/ca`,
`/CA`, and `/BM`. Each nonzero state is applied inside balanced `q/Q`
scope around the existing operation bytes.

## Qualification

Focused tests cover validation/deduplication, V1/V2 state-zero byte identity,
invalid state IDs, all supported draw operation families, direct ExtGState
inspection, opacity/blend rendering, RGBA soft-mask × external opacity
composition, deterministic finish, and installed-package linkage.
