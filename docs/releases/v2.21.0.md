# QuantaPDF 2.21.0

## Added

- `quantapdf_composer_form_id`.
- `quantapdf_composer_form_options`.
- synchronous `quantapdf_composer_form_builder_fn`.
- `quantapdf_composer_add_form()`.
- `quantapdf_composer_draw_form()` with displayed-space affine placement and
  optional existing graphics-state attachment.

## Builder model

A form builder receives a temporary transparent single-page child Composer and
uses the ordinary Composer APIs. On successful return, QuantaPDF serializes the
child deterministically, drops it, deduplicates by dimensions plus exact PDF
bytes, and stores only the immutable one-page snapshot.

Navigation and outlines are not Form content.

Nested forms are naturally acyclic because only completed child snapshots can
be referenced.

## Backend

Stored snapshots are converted through qpdf's
`QPDFPageObjectHelper::getFormXObjectForPage()` and imported with
`copyForeignObject()`. Child fonts, images, gradients, ExtGState resources,
clips, nested forms, and ToUnicode mappings remain isolated inside the Form
XObject.

Only referenced form snapshots are imported into the parent PDF. A referenced
form requiring PDF 1.6 propagates that minimum version to the parent.

## Placement

For form height H, public displayed transform [a b c d e f] lowers to:

```text
[a, -b, -c, d,
 c*H + e,
 page_height - d*H - f]
```

The all-zero transform record means identity.

## Qualification

Focused tests cover callback/argument errors, exact-byte deduplication,
resource-budget failure, transparency, direct /Subtype /Form and BBox
inspection, translation/rotation, outer opacity+clip state, nested forms,
text extraction, PDFium rendering, deterministic repeated finish, and the
installed-package consumer.
