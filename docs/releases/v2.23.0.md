# QuantaPDF 2.23.0

## SVG V2B1

The bounded static SVG lowering path now supports a safe local definition graph
for:

- userSpaceOnUse linear gradients;
- userSpaceOnUse radial gradients;
- opaque gradient stops;
- userSpaceOnUse clipPath resources;
- fragment-local fill/stroke/clip-path url(#id) references.

A side-effect-free definition pre-pass collects unique IDs and supported
resources before the ordinary render pass, so forward references are supported
without mutating the Composer during parse.

## Gradient semantics

V1 requires explicit gradientUnits="userSpaceOnUse" and PAD spread.
objectBoundingBox, percentage gradient coordinates, template href, and
non-opaque stops remain fail-closed.

Missing endpoint stops are synthesized at 0 and/or 1. Stop offsets otherwise
remain strictly increasing.

Referenced gradient transforms compose with the referencing element's SVG
transform and lower to the existing Composer paint resource.

## Clip semantics

clipPath supports absent/userSpaceOnUse units plus supported local shapes/groups
and transforms. It lowers to the existing Composer clip resource.

Root/group clip-path consumers, nested clip references, and simultaneous
preserveAspectRatio=slice plus explicit clip-path remain unsupported rather than
approximated.

## Transactional behavior

Paint, clip, and graphics-state resources are registered only during final
publish under rollback snapshots. A failed SVG draw restores paint/clip/state
counts and resource bytes and publishes no operations.

## Compatibility

No new public ABI symbols are added. ABI v2 is unchanged.

Reusable symbol/use definitions remain SVG V2B2.

## Qualification

Focused tests cover forward gradient/clip references, linear/radial resource
inspection, transformed clipping, wrong-kind/unresolved/external refs,
duplicate IDs, unsupported unit/stop semantics, transactional budget rollback,
deterministic output, PDFium rendering, and the installed package consumer.
