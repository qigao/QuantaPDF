# QuantaPDF 2.14.0

## Added

- `quantapdf_composer_measure_text()` for Base-14/WinAnsi layout preflight.
- `quantapdf_composer_measure_embedded_text()` for registered SFNT fonts.
- `quantapdf_composer_text_measurement` with tight width, baseline-model
  height, and line count.

## Architecture

Text measurement and qpdf emission now consume one backend-neutral private
layout core. Existing drawing APIs, operation records, ownership rules, and ABI
version remain unchanged.

## Qualification

The feature is covered by focused Base-14 and embedded-font measurement tests,
draw/measure line-count agreement, invalid-input/output-reset checks, and the
installed-package consumer.
