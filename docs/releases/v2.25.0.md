# QuantaPDF 2.25.0

## Added

Reusable Composer Forms now support optional PDF transparency-group semantics.

`quantapdf_composer_form_options` gains a V2 `flags` tail with:

- `QUANTAPDF_COMPOSER_FORM_FLAG_TRANSPARENCY_GROUP`;
- `QUANTAPDF_COMPOSER_FORM_FLAG_ISOLATED`;
- `QUANTAPDF_COMPOSER_FORM_FLAG_KNOCKOUT`.

## Compatibility

The V1 Form-options size remains the pre-2.25 layout and implies flags=0.
Ordinary V1 Forms therefore emit no /Group dictionary and remain byte-compatible
with prior output.

V2 flags=0 is qualified byte-identically to V1.

## Semantics

Isolated and knockout flags require transparency-group to be enabled. Unknown
bits are rejected.

Form deduplication includes the flags value in addition to dimensions and exact
serialized child-PDF bytes.

## Backend

Flagged Forms receive a native PDF transparency-group dictionary:

```text
/Group <<
  /S /Transparency
  /CS /DeviceRGB
  /I true|false
  /K true|false
>>
```

The existing draw_form() graphics-state attachment is unchanged, allowing outer
opacity/blend to composite the completed Form group.

## Qualification

Focused tests cover validation/deduplication, V1/V2 zero-flag identity, direct
Group inspection, overlapping-child group compositing, nested transparency
Forms, deterministic rendering, and the installed-package consumer.
