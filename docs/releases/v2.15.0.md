# QuantaPDF 2.15.0

## Added

- `quantapdf_affine_transform`, a backend-neutral displayed-page-space affine
  value.
- `quantapdf_composer_draw_text_transformed()`.
- `quantapdf_composer_draw_embedded_text_transformed()`.
- `quantapdf_composer_draw_glyph_run_transformed()`.

## Semantics

Local points are mapped as:

```text
X = a*x + c*y + e
Y = b*x + d*y + f
```

Text layout remains local: wrapping/alignment and vertical line admission use
the existing bounds before the transform is applied. Caller-shaped glyph-run
advances and offsets retain their existing local displayed-space semantics.

Existing drawing APIs lower through the same implementation with the identity
transform, preserving their contracts.

## Qualification

The focused affine suite covers identity byte equivalence, 90/180/270 degree
rotation, arbitrary finite rotation, embedded Unicode text, positioned glyph
runs with advance/offset, qpdf content matrices, PDFium rendering/extraction,
determinism, invalid transforms, and installed-package linkage.
