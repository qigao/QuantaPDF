# QuantaPDF 2.19.0

## Added

- reusable quantapdf_composer_paint_id;
- bounded copied gradient-stop arrays;
- quantapdf_composer_add_linear_gradient();
- quantapdf_composer_add_radial_gradient();
- V3 path-option tails for gradient fill and stroke paint.

## Semantics

V1 gradients require 2..64 opaque sRGB stops with strictly increasing offsets
from exactly 0 to exactly 1. Linear endpoints must differ. Radial radii are
nonnegative and the two circles may not be identical.

The all-zero gradient transform is identity; any other transform must be finite
and non-singular. V1 spread is PAD only.

Paint ID 0 preserves the existing solid ARGB path.

## Backend

Linear/radial resources lower to PDF axial/radial shadings. Two-stop gradients
use FunctionType 2; multi-stop gradients use FunctionType 3 stitching.
Page-specific PatternType 2 wrappers apply displayed-space transform and
y-axis conversion. Generic PATH content selects Pattern color space for fill
or stroke.

## Compatibility

Path V1 and V2 sizes retain their existing ABI boundaries. V3 appends
size_t-aligned fill/stroke paint IDs after the V2 boundary. Existing solid and
dashed path APIs remain unchanged and produce no Pattern resources for paint
ID 0.

## Qualification

Focused tests cover validation, ownership/accounting, deduplication, V2/V3
identity, direct Pattern/Shading/Function inspection, linear/radial and
multi-stop rendering, transformed gradients, gradient stroke, deterministic
finish, and installed-package linkage.
