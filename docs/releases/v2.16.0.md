# QuantaPDF 2.16.0

## Added

- `quantapdf_composer_dash_pattern`.
- `quantapdf_composer_draw_path_dashed()`.
- A bounded 64-element dash-array contract with copied caller storage.

## Semantics

Dash lengths are finite and nonnegative, with at least one positive element.
Zero-length elements are permitted. Phase is finite and nonnegative. Dashed
drawing requires stroke to be enabled in the existing
`quantapdf_composer_path_options`.

Command and dash storage are charged together to the Composer resource budget,
and failure is transactional.

## Compatibility

The existing path-options record and `quantapdf_composer_draw_path()` are
unchanged. Solid paths continue to emit no PDF dash operator.

## Qualification

Focused tests cover validation, ownership, capacity/resource boundaries, PDF
content evidence, PDFium rendering, deterministic finish, and the
installed-package consumer.
