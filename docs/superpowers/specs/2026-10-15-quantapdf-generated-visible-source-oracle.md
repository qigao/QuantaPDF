# #269 test-owned original PDFium vs native visible-device Fill + W Clip

This PR is stacked on the exact passed [Draft #332](https://github.com/qigao/QuantaPDF/pull/332).
It adds a separate **generated-source original PDF** test using the same
independent test-only QPDF writer and PDFium path already present in the
native source oracle, without altering the 14-family/36-fixture
source-corpus manifest, external corpus, original jsPDF source, or SDK.

## Data flow

1. Build an actual PDF source file: one page with MediaBox [0 0 20 30],
   CropBox [2 3 12 11] (alternately inherited or local), inherited/local
   Rotate 0/90/180/270, leaf /UserUnit 1 or 2, and native PDF content
   `3 4 6 6 re W n 1 0 0 rg 4 5 6 4 re f`.
2. Open **those original bytes** through QuantaPDF, capture the Graph,
   lower one Page into an owned Composer IR and then close/drop the source
   document and Graph Snapshot *before* C11 Raster.
3. Pass the source metadata and that *already-normalized* IR into the
   explicit private Fill+Clip preview from #332, with independently
   bounded pixels/edges/4×4 samples/RGBA bytes.
4. Independently open and render the **unaltered original PDF** with
   the installed test-only PDFium path. Compare dimensions, source-space
   interior red and exterior white pixel samples, and whole-page RGB8
   absolute error / differing pixels / gross error / max channel difference.
   Report actual metrics rather than declaring zero-error parity.
5. Repeat the C11 render and verify the result is byte-identical.
   All source coordinates remain borrowed; no writer/re-export PDF is
   fed into PDFium as the test oracle.

The eight cases are 4 intrinsic rotations × 2 UserUnit settings at the
default original-PDFium device pixel layout. 72/96/144 DPI synthetic C11
projection was separately qualified by #332. A later independent
same-page actual-original PDFium multi-DPI acceptance is required.

## This does not authorize production

The original is **generated by a test**, not an independently published,
license-qualified producer artifact. This first source-backed test uses
bounded coarse pixel error thresholds plus exact interior/exterior
goldens; it does **not** prove full anti-aliasing parity. It cannot
increase formal external source/native-positive totals and does not
qualify general Stroke, arbitrary CTM, W*, or another provider.

The new oracle is a separate CTest mode, isolated from the existing
source corpus report and installed SDK tests; the private Raster remains
compiled only in tests. Keep #269 OPEN, all stacked PRs Draft /
DO NOT MERGE, public SDK PDFium, #208 backend cutover blocked.
