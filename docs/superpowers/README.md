# Historical plans and specifications

The files under `plans/` and `specs/` record earlier designs and implementation
work. Their compatibility promises, staged admission gates and proposed
platform frameworks are superseded by the 2026-11-03 reset.

Current authority:

- [Repository development rules](../../AGENTS.md)
- [Native feature plan and missing capabilities](../native-feature-plan.md)
- [Current SDK notes](../native-sdk.md)
- [Product verification](../product-conformance.md)

Reuse a historical algorithm or measured fixture when it helps the current
feature. Do not use an older specification to require API/ABI compatibility,
defensive programming, old providers, installer/consumer projects or a new
framework before implementing a PDF operation.
