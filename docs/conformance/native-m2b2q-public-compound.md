# M2b.2q: public compound Clip Text/Fill/Image Bitmap

The existing public Source V10 preparation path admits the exact compound
graph qualified by M2b.2o/p: two independent original identity-space rectangular
W/W* leaves, one flat Intersection(1,2) root, one opaque Normal GS naming root3,
and ordered Text→Fill→Image operations naming GS1. The allocation-free metadata
classifier validates member IDs, transforms, both leaves, GS and paint order.
The common resource closure accounts for both leaves plus the intersection
member array; its used-state and used-Clip masks are 1 and 7.

The selected route calls the existing M2b.2p V5 compiler. Source ownership,
Context leases, the address-stable compiled page, correlated glyph/leaf samples,
Fill/Image masks, compositor, global ledger and detached RGB storage use their
existing implementations. There is no additional parser, raster or public ABI.
The 8M sample/512 edge ceilings, Image/Fill 1/8 sample shares, child edge limits,
four-operation ceiling and source/full-placement/output/memory policy stay
unchanged.

Original RAW/Flate 126/127 and 145/146 compare every public RGB byte at
72/96/144 DPI against unchanged original-quadratic glyph sample planes and
analytic independent leaf/Fill/Image coverage. The newer pair has nonempty
coverage in all three layers; each DPI retains visible dropped-leaf controls
and spurious ink under incorrect separate averaged glyph/leaf/leaf alpha
multiplication. All twelve compound Bitmaps survive Page, Document and caller
Context teardown, together with the six existing sibling outputs. Their
references are independent of the successful Bitmaps.

The existing Context/OOM test exercises all four compound originals at all
three DPIs: real Bitmap storage refusal, Bitmap/prepared-Source retain overflow,
balanced references, exact same-Context retries and exactly one final Context
destruction after retained Bitmap disposal. The prepared receipt/fault suite
exercises both newer originals at 96 DPI: every reached Source C and C11
allocation fault, empty IR or output/receipt, immutable Source snapshots and
full-byte recovery. Operations, source/full-placement/output pixels, peak
bytes and measured sample/edge admission have N/N−1 checks. Source ownership
and private V5 suites retain their previously accepted fault and budget cases.

The original malformed scopes, changed CTM, third/late root, post-restore
paints, reverse order, missing n, hidden resource and off-lattice/no-Text cases
still refuse before public same-Context recovery on all qualified profiles.
Malformed borrowed member graphs and bindings still refuse preparation; the
private compiler retains its zero-allocation refusal checks.

This bounded candidate admits only the original three-paint dual-rectangle
intersection profile. More general Clip DAGs/contours, reverse sibling order,
wider fonts/matrices and remaining budget-boundary evidence stay open under
#584/#580/#570/#208. Existing golden assets, test executables/registrations,
