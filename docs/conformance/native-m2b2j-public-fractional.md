# M2b.2j: public original fractional Text/Clip

The public Source V10 adapter removes the physical-pixel alignment gate
only for the already bounded three-paint Text/Fill/Image profile under one
axis-aligned W/W* root, in either original order. All existing resource,
operation, font, opaque-paint and physical-device predicates remain. The
Q-restored fourth red Fill retains its original pixel-aligned Clip gate.
The same typed operation compiler, V5 owner, ledger and 4x4 sampler execute
the admitted original. No new parser, renderer, public ABI or quota is added.

This increment depends on the independent original-glyph samples in #596
(M2b.2i). The sample files and all historical RGBA goldens are unchanged.
The test-only reference helper imports no Source or production raster code.
It intersects each separate original-quadratic glyph mask with independently
calculated authored Clip samples before per-glyph rounding, then composites
analytic Fill/Image coverage and original RGB samples in source order.

The existing native executables provide these checks without new test
registration, targets, workflows or timeout changes:

- Public render: original fixtures 83/84 (including their previously refused
  96-DPI edges) and quarter-point fixtures 99/100, both orders and W/W*,
  compare every RGB byte at 72/96/144 DPI. Each quarter-point DPI must contain
  disjoint nonempty marginal masks, partial intersections and visible
  spurious ink under the deliberately wrong rounded-alpha product.
- Fractional excess Q, late W, skew/cubic Clip roots and a fractional
  Q-restored fourth Fill refuse the whole original with an empty Bitmap.
  The same Context then reproduces the complete independent image. A held
  96-DPI Bitmap matches that oracle after all source/Context handles retire.
- Source/OOM: both quarter-point orders at 96 DPI fail every reached Source
  C and ledger-backed C11 allocation; failures publish empty IR or zero
  image/receipt. Retried complete bytes match the independent reference.
  Source pixels, output pixels, operations, drawn pixels and peak bytes have
  N/N−1 checks. Minimum admitted sample/edge caps are measured under the
  unchanged fixed child shares and checked at N/N−1, separately from billed
  work.
- Context/OOM: both quarter-point orders at all three DPIs exercise actual
  public Bitmap storage NOMEM and both reference-overflow positions,
  balanced references, independent complete-byte retries, retained pixels
  and exactly one final Context destruction.

This is candidate-branch scope until its exact HEAD and independent merged
master CI pass. #584/#580/#570/#208 remain open for fractional four-paint
restoration, sibling/compound roots and broader orders/fonts/matrices.
