# M2b.2r: reverse sibling Source ownership

This bounded Source increment admits the reverse original order: q saves
GS0, rectangular W/W* plus n defines leaf1, and Image then Fill observe
leaf1. A real Q restores GS0. A new q saves GS0 and a second rectangular
W/W* plus n defines the independent leaf2 before the original Text show.
The final Q restores GS0. The BT handoff accepts only identity current and
saved CTMs, with saved Clip IDs [0] or [0,2] when Text has its own q frame.

The existing pre-BT content reader freezes the Image/Fill prefix and both
authored leaves. Its same outline-reader handoff carries leaf2 and the
original saved graphics frames across BT. Only Text may follow that prefix;
the existing q/Q callback observes the actual final restoration. At complete
original EOF the shared three-paint materializer and Clip publisher own two
independent PATH leaves and two opaque Normal graphics states. Ordered
Image/Fill/Text operations name GS [1,1,2]; GS1/GS2 name leaf1/leaf2.
Neither an intersection nor the final global Clip substitutes for a paint's
frozen identity. The existing forward sibling and compound profiles retain
their admission and allocation order.

QPDF-authored originals 147/148 use RAW/Flate RGB Image data and swap W/W*
rules. The existing Source/OOM invocation compares every glyph/Fill command,
decoded Image byte and full Image placement with the accepted original
single-root reverse source. Both leaf arrays and all payloads are independently
owned and remain valid after the input PDF bytes retire. The real C++ saved
stack allocation at BT and every reached Source C publication allocation
are faulted. Failure clears the complete IR; retries and disposal succeed.
Source operations, Image source pixels and full placement have exact N/N−1
checks (3/2, 4/3 and 192/191).

Originals 149–167 exercise missing/excess Q, inherited rather than sibling
Clip, third Clip, late Image/Fill/Text, changed CTM, absent Text or n, unknown
Do, extra Font alias, off-lattice/skew/cubic leaf, missing prefix Fill,
missing new q, wrong prefix order and Clip2 restored before Text. They refuse
atomically; a valid reverse Source retries after each negative. Source
snapshots remain unchanged through prepared admission and private V5 refusal
at 72/96/144 DPI. Private sibling compilation refuses before any allocation.
Actual public Bitmap calls still refuse both positive originals at all three
DPIs, then recover accepted single, forward sibling and compound originals
in the same Context with unchanged independent RGB references and retained
Bitmap lifetime checks.

This qualifies Source ownership only. Reverse sibling private V5 pixels and
public preparation/receipts/Bitmaps require their own increments. Public ABI,
numerical caps/shares, old fixture bytes/goldens, test executables and
registrations, CMake/workflow and timeouts remain unchanged. Wider Clip
graphs/contours, fonts and matrices remain open under #584/#580/#570/#208.
Candidate CI and independent master CI after merge remain separate gates.
