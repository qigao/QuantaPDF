# M2b.2 — correlated opaque Text / Fill / Image and original frozen W/W* Clip

Tracks [#584](https://github.com/qigao/QuantaPDF/issues/584), parent [#580](https://github.com/qigao/QuantaPDF/issues/580). This is a **bounded future public Source admission**, not an implementation claim.

## Accepted starting point

M2b.1 [#583](https://github.com/qigao/QuantaPDF/pull/583) merged as master `d0d4dd27c86450659f4a462fa55acc87d7d8275b`; [master-push CI #2320](https://github.com/qigao/QuantaPDF/actions/runs/41431432133) SUCCESS 3/3, 67/67 native and installed 1/1 on each platform. Its one QPDF token pass, unique Source-owned IR, one Context/ledger and single C11 V5 compiler/compositor admit opaque black CID TrueType, one rectangular Fill, one RAW/Flate Image in both authored orders **without W/W***.

## Technical gate, in order

1. **M2b.2a private exact intersection:** `qp_text_glyph_mask` already computes 16-bit coverage on 4×4 device subpixels. Privately accept ONE qualified frozen five-command Clip leaf (W or W*, no transform, bounded) and intersect its existing C11 winding predicate with the glyph at those **same** 16 device positions, before the old compositor rounds to output RGBA. Both disjoint edge masks have nonzero marginal coverage yet their exact AND may be empty; multiplying averaged 8-bit alpha values is an incorrect alternative. Reuse the same compiled geometry owner, fault path and exact-work ledger. This is staged in [Draft PR #585](https://github.com/qigao/QuantaPDF/pull/585), not a public Source switch.
2. **Complete original Source semantics:** extend the same `image_content_reader`→`source_text_outlines` handoff, never parse a second Content stream. Freeze canonical Clip root/CTM/color and q/Q stack at each Text, Fill or Image paint completion. W/W* followed by `n` commits a Clip *without ink*. A Q restores only subsequent paint membership; already stored paints do not mutate. All original operations, resources, late invalid tokens and full EOF must be validated before detached IR publication. Reject extra/unreferenced Font, XObject, ExtGState, second unsupported Clip, malformed stack, invisibly unsupported paint.
3. **Unique owned IR and V5 execution:** preserve all authored op order, exact Clip/GS identity per operation and only one lifetime domain. Prepare one Text-Clip geometry, Fill-Clip geometry and Image-Clip mask using the already-existing V1/V5 sampler/owner; image nearest-neighbor color stays independent from its *geometric* 4×4 Clip sample phase. One page-wide max 4 authored ops, 64 glyphs, 4096 commands, 512 edges, 1M pixels, 8M total sample-work, decoded source/placement/live/retained bytes. Neither a per-layer work reset nor another full-page bitmap producer is admissible.
4. **Independent actual Source goldens:** original QPDF-created Text→Fill→Image, Image→Fill→Text, W/W* and q/Q restored suffix at 72, 96 and 144 DPI, exact every output RGB byte. Verify correlated intersecting and disjoint edge subpixels from *independent* glyph/Clip geometry—not from already-averaged Roboto RGBA nor a production-compositor-generated golden. Include sibling Clip leaves and Image-before-Clip, then Q-restored no-Clip paint only within original four-paint cap. Maintain all historical M1/M2a/M2b.1 exact bytes.
5. **Fault and resource gate:** actual public original Source N/N−1 on authored/expanded operations, glyphs, commands, edges, work, source/drawn/output pixels, requested/retained/peak bytes; real Source and C11 malloc failure at every reached slot, empty Bitmap+receipt, balanced Context and same-Context recovery. No public ABI changes, new workflow, installer/consumer test project, probe CMake/CI or PDFium fallback.

## Current scope statement

A green **private** M2b.2a CI proves only correlated C11 glyph/Clip coverage plus measured budgets and memory faults. It does **not** prove original Source W/W*, operation-root propagation, mixed V5 ownership or full public PDF Text+Clip. Those require distinct exact-head and independent master-push CI. Keep #584/#580/#570/#208 OPEN until their explicit gates pass.
